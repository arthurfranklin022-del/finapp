# src/components

Peças de tela reaproveitáveis.

- `DemoBar.jsx`: barra do modo demo (áreas + persona). Esconde com o botão ou a tecla **D**.
- `PhoneFrame.jsx`: moldura de celular no notebook; no celular, tela cheia.
- `Logo.jsx`: marca Finapp com o Broto.
- `ComingSoon.jsx`: aviso "Chega na Etapa X".
- `brand/`: desenhos do Broto (mascote escolhido) e das outras opções da comparação.
